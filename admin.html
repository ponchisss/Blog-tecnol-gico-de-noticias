Buzón de Gmail Virtual (Desarrollo)

Este buzón simula los correos enviados por la aplicación. Cuando creas una nueva cuenta para un usuario, el código de verificación de 6 dígitos se registrará aquí para que puedas copiarlo y verificar tu cuenta de pruebas inmediatamente.

Configuración de Envío de Correo Real (EmailJS)

Activa el envío de correos reales a tus usuarios. Esto conectará el flujo de registro del blog a la API segura de EmailJS, permitiendo enviar códigos de verificación reales a cuentas de Gmail o cualquier otro proveedor sin necesidad de un backend.

¿Cómo configurar EmailJS gratis?

  1. Regístrate gratis en emailjs.com.
  2. En Email Services, añade tu servicio de Gmail (copia el Service ID).
  3. En Email Templates, crea una plantilla de correo que tenga las siguientes variables:
    {{to_email}} para el destinatario.
    {{code}} para incluir el código de 6 dígitos.
    (Copia el Template ID).
  4. En tu perfil de EmailJS, ve a API Keys y copia la Public Key.
  5. Pega las llaves en los campos de arriba y presiona "Guardar Configuración". ¡Y listo! Los usuarios de prueba recibirán correos de verdad.
